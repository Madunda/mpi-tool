# Multidimensional Poverty Index Tool

A Streamlit application for configuring and analysing an Alkire-Foster
Multidimensional Poverty Index (MPI).

## Run the application

From this folder, run:

```powershell
..\mpi\Scripts\python.exe -m streamlit run app.py
```

The application opens in your default browser. Use the **Load Dataset** page
to upload a CSV, Excel, or Stata dataset before configuring indicators.
